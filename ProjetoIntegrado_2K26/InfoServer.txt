============================================================
              CONTRATO DA API - MONITORAR
============================================================


1. OBJETIVO
------------------------------------------------------------

A API recebe as medições do C#, envia o ADC para o
classificador Python, armazena o resultado e fornece
os dados para o Dashboard.

Fluxo:

STM32 / Simulador
        |
        | COM + protocolo proprietário
        v
       C#
        |
        | HTTP + JSON
        v
     Node.js
        |
        | ADC
        v
     Python
        |
        | CO2 + qualidade
        v
     Node.js
        |
        +------> C#
        |
        +------> Dashboard


============================================================
2. CONFIGURAÇÃO
============================================================

Tecnologias:

    Node.js
    Express

Porta:

    3000

Endereço:

    http://localhost:3000


============================================================
3. POST /classificar
============================================================

FINALIDADE:

Receber uma medição do C# e solicitar a classificação
ao Python.


MÉTODO:

    POST


ENDPOINT:

    /classificar


CONTENT-TYPE:

    application/json


------------------------------------------------------------
DADOS ENVIADOS PELO C#
------------------------------------------------------------

Exemplo:

{
    "adc": 2048,
    "filtro": false
}


CAMPO: adc

Tipo:

    number

Descrição:

    Valor bruto recebido pelo ADC.

Faixa:

    0 até 4095


CAMPO: filtro

Tipo:

    boolean

Descrição:

    Indica se o filtro está ativado.

Valores:

    true  = ativado
    false = desativado


============================================================
4. VALIDAÇÃO
============================================================

O Node.js verifica:

    - se ADC foi enviado;
    - se filtro foi enviado;
    - se ADC é um número;
    - se ADC está entre 0 e 4095;
    - se filtro é true ou false.


------------------------------------------------------------
ADC OU FILTRO AUSENTE
------------------------------------------------------------

HTTP:

    400 Bad Request

Resposta:

{
    "erro": "ADC ou filtro nao enviado"
}


------------------------------------------------------------
ADC INVÁLIDO
------------------------------------------------------------

HTTP:

    400 Bad Request

Resposta:

{
    "erro": "ADC invalido. Deve estar entre 0 e 4095"
}


------------------------------------------------------------
FILTRO INVÁLIDO
------------------------------------------------------------

HTTP:

    400 Bad Request

Resposta:

{
    "erro": "Filtro invalido. Deve ser true ou false"
}


============================================================
5. COMUNICAÇÃO COM O PYTHON
============================================================

Depois de validar o ADC, o Node.js executa:

    py ClassificadorArvore.py 2048


O ADC é enviado para o Python como argumento.

O Python converte o ADC para CO₂ em ppm e realiza
a classificação da qualidade do ar.


Conversão:

    CO2 = (ADC * 5000) / 4095


Exemplo de resposta do Python:

{
    "adc": 2048,
    "co2": 2500,
    "qualidade": "Moderada"
}


============================================================
6. RESPOSTA DO POST /classificar
============================================================

Se o processamento ocorrer corretamente:

HTTP:

    200 OK


Resposta:

{
    "adc": 2048,
    "co2": 2500,
    "qualidade": "Moderada"
}


Campos:

    adc
        Valor original do ADC.

    co2
        Concentração de CO₂ em ppm.

    qualidade
        Classificação produzida pela Árvore de Decisão.


Possíveis classificações:

    Excelente
    Boa
    Moderada
    Ruim
    Critica


============================================================
7. ERROS DO PYTHON
============================================================

Se ocorrer um erro ao executar o Python:

HTTP:

    500 Internal Server Error


Resposta:

{
    "erro": "Erro ao executar o Python",
    "detalhes": "mensagem do erro"
}


Se o Python não retornar um JSON válido:

HTTP:

    500 Internal Server Error


Resposta:

{
    "erro": "Resposta invalida do Python"
}


============================================================
8. HISTÓRICO
============================================================

O Node.js mantém as últimas 20 medições em memória.

Cada medição possui:

    adc
    co2
    qualidade
    filtro
    horario


Exemplo:

{
    "adc": 2048,
    "co2": 2500,
    "qualidade": "Moderada",
    "filtro": false,
    "horario": "2026-08-16T18:00:00.000Z"
}


Quando o histórico ultrapassa 20 medições,
a medição mais antiga é removida.

10. GET /estatisticas
============================================================

FINALIDADE:

Calcular estatísticas das medições de CO₂ armazenadas.


MÉTODO:

    GET


ENDPOINT:

    /estatisticas


Exemplo:

{

    maximo

        Menor valor de CO₂ em ppm.


Se não houver medições:

{
}

============================================================
12. FLUXO DE UMA MEDIÇÃO
============================================================

1. O sensor ou simulador gera um ADC.

2. O ADC é enviado pela porta COM.

3. O C# recebe o protocolo proprietário.

4. O C# extrai:
       - ADC
       - filtro

5. O C# envia para o Node.js:

       POST /classificar

       {
           "adc": 2048,
           "filtro": false
       }

6. O Node.js valida os dados.

7. O Node.js executa o Python:

       py ClassificadorArvore.py 2048

8. O Python converte:

       ADC → CO₂ em ppm

9. O Python classifica a qualidade do ar.

10. O Python retorna:

       {
           "adc": 2048,
           "co2": 2500,
           "qualidade": "Moderada"
       }

11. O Node.js adiciona:

       - filtro
       - horário

12. O Node.js salva a medição no histórico.

13. O Node.js envia o resultado para o C#.

14. O Dashboard consulta:

       GET /historico

       GET /estatisticas

15. O Dashboard apresenta os dados.


============================================================
13. RESUMO DOS ENDPOINTS
============================================================

POST /classificar

    Recebe ADC e filtro do C# e solicita
    a classificação ao Python.


GET /historico

    Retorna as últimas 20 medições.


GET /estatisticas

    Retorna média, maior e menor valor de CO₂.


GET /

    Abre o Dashboard.


============================================================
14. CÓDIGOS HTTP
============================================================

200 OK

    Requisição processada corretamente.


400 Bad Request

    Dados enviados são inválidos ou estão incompletos.


500 Internal Server Error

    Erro interno no processamento ou na execução
    do Python.


============================================================
15. TECNOLOGIAS
============================================================

C#:

    Recebe os dados da porta COM e envia
    requisições HTTP para o Node.js.


Node.js + Express:

    Recebe e valida os dados, executa o Python,
    mantém o histórico e fornece os dados
    para o Dashboard.


Python:

    Converte o ADC para CO₂ em ppm e classifica
    a qualidade do ar usando uma Árvore de Decisão.


Dashboard:

    Exibe CO₂, ADC, qualidade, filtro, histórico,
    estatísticas, gráfico e tendência.


Comunicação C# → Node.js:

    HTTP + JSON


Comunicação Node.js → Python:

    Argumento de linha de comando + JSON
